# FRDb – Film Review Database

An IMDb-inspired movie database developed as a university project at Uppsala University. Built with PHP, SQLite, JavaScript, HTML and CSS, the application combines movie discovery, user interaction and external API integrations.

## Features

- **Movie Discovery** – Explore movies and access detailed information through the TMDb API.
- **User Authentication** – User accounts with authentication and role-based access.
- **Watchlists & Ratings** – Save movies to personal watchlists and rate films.
- **Social Features** – Manage friends and interact through user profiles.
- **Weather-Based Recommendations** – Dynamic recommendations using real-time weather data from Open-Meteo:
  - ☀️ **Nice weather** → Recommends an outdoor activity.
  - 🌧️ **Bad weather** → Recommends a movie.

## Tech Stack

| Category | Technologies |
|---|---|
| Backend | PHP 8 |
| Frontend | HTML, CSS, JavaScript |
| Database | SQLite |
| External APIs | TMDb, Open-Meteo |
| Architecture | Server-side web application |
